What is this app for?

Draw a handwritten digit from 0 to 9 and convert it into pixel data for a Python model. The drawing is reduced to a 20×20 grayscale image, with pixel values normalized between 0 and 1.

Use the resulting NumPy array to test a handwritten-digit recognition neural network. The output contains one row of 400 values, representing the 20×20 pixels. You can edit the array or change its variable name before copying it into your Python code.
